Every inbox item is a machine stopped somewhere, so the row draws the machine: a six-stage strip — plan, branch, build, e2e, pr, g3 — with a diamond on the stage where it halted. Status is read off position before colour, which means the operator learns the shape of the pipeline just by triaging it. Visible column rules keep six heterogeneous item types in one comparable table; the detail view redraws the same pipeline vertically as a run map, so the stage that stopped is fixed in the same place on both screens.
