# Reconciliation review — PRD / addendum vs spine

**Verdict: the spine governs the PRD's shape (every FR has a capability-map row, every technology change is declared in prd-deltas) but drops a cluster of runtime rules that the AD structure had no slot for, and its step state machine cannot express two PRD behaviours (Skip, already-done Stories). One high, nine medium, ten low findings. Nothing requires a new AD; each fix is a sentence in an existing AD, a convention row, a Deferred bullet, or a prd-deltas row.**

Severity key: **high** = a story built from the spine as written would contradict a MUST requirement; **medium** = a MUST/SHOULD rule has no home and will be reinvented per epic; **low** = COULD tier, cosmetic, or a one-line declaration missing.
