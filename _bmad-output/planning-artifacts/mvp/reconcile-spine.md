# Reconciliation — PRD vs architecture spine (2026-09-02)

Method: every FR, glossary entry, NFR and addendum section read against AD-1..AD-20, the conventions table, the structural seed ("Template DSL v1 keys", "Shipped kinds", entity fields), the capability map and the deferred list. Implementation detail the PRD leaves to the spine (module names, ports, stack) is ignored unless the PRD states it wrongly. Severity: **high** = a builder would build the wrong thing; **medium** = builder must choose between two stated behaviours or invent a missing mechanism; **low** = wording, example or scope drift.

Counts: high 1 · medium 10 · low 21.
