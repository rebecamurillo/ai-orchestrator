- (event) RESEARCH FINDING (workflow engines): CNCF Serverless Workflow DSL was renamed the Open Workflow Specification (open-workflow-specification.org), currently 1.0.3, still CNCF Sandbox. There is NO Python runtime: the official sdk-python is a validator/data-model only, pinned to spec 0.8, last released 2022-04, and its 1.0 migration PR has sat unmerged for 7 months. Only JVM runtimes implement 1.0. Adopting the DSL as specified means writing and maintaining our own interpreter. This independently confirms the forge decision to reject it for the PoC.
- (event) RESEARCH FINDING (DBOS): library is MIT and needs only Postgres, no DBOS Cloud. Human-in-the-loop is first-class and documented for this exact case: DBOS.recv/send with durable waits that survive restarts and code upgrades, plus durable sleep with no documented cap. list_workflows with JSONB attributes gives the query surface an approval inbox needs. Confirms DBOS as a sound engine choice.
- (event) RESEARCH FINDING (DBOS risk): app version = hash of workflow source. DBOS only recovers workflows whose version matches the current app version, so deploying code strands in-flight workflows unless old-version processes drain. With day-long human gates this is a real operational cost. Mitigations: DBOS.patch and fork_workflow(application_version=).
- (event) RESEARCH FINDING (DBOS risk, sharpest): if the WORKFLOW YAML changes while runs are in flight, the DBOS app version does NOT change (interpreter source is stable), so DBOS recovers an old run against new YAML and hits DBOSUnexpectedStepError. The DSL document must be versioned explicitly and each run pinned to its document version. Flagged by research as the single highest-risk item.
- (event) RESEARCH FINDING (DBOS risk, scaling): FAQ states Conductor is required for correct workflow recovery across more than one process; docs allow self-managing via static executor_id per process, but a crashed executor's workflows are not picked up by peers until that ID returns. Directly taxes the stated v2 multi-container plan. Conductor self-hosted is proprietary and paid (Pro $99/mo, Teams $499/mo).
