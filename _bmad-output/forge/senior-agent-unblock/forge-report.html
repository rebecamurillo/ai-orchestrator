Senior consult and team chat

Blocked agents ask a senior session first. Only what it cannot settle reaches a human, in the team's own channel.

Locked decisions

  • Test changes justified by the story need no human; the senior reviews the real diff and sends anything else to a human.
  • Triggers: blocked, protected_path on tests only, and verify_failed after retries. Limit: one consult per row per stop kind.
  • The senior only advises. The original agent is the one resumed and makes every edit.
  • One channel per Project: off, Slack or Mattermost. One port, two adapters, polling from the host.
  • One thread per question, closed for good once answered. Replies are routed by stored thread ID, never by message text.
  • Reminders every 4 hours while parked.

Rejected

  • Mattermost in deploy/: the team already has a host, and official images are amd64 only.
  • Threads per agent, story or epic: a late reply could answer the wrong question.
  • Inbound webhooks: they need exposure that polling avoids.

Weak points that survived

  • Agents approving agents: no human may see a test change before it merges. The separate review stage and the audit record are the only checks.
  • Spec defects: the one real blocked Run needed 4 operator spec edits for 11 stops, and the senior cannot edit the spec.
  • Self-rated doubt: a senior may under-escalate, so explicit must-escalate cases carry the weight.
  • Thin evidence: one real Run. Its protected_path count means nothing, because empty test_globs froze no test file.
  • Not tested: Tailscale Serve login, and reaching the Mattermost host from the backend container.
