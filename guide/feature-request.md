# Asking for a feature

Ask for a feature only after a workflow was tried and cannot do the job. When no workflow has
been drafted yet, `workflows/would-a-workflow-do-it` comes first.

1. Search the open and closed issues of https://github.com/rebecamurillo/ai-orchestrator for
   the same request.
2. Draft the issue on the `from-client-agent` form (`.github/ISSUE_TEMPLATE/from-client-agent.yml`):
   what the user wanted to do, what the agent tried (the workflow it drafted and the findings
   it got), why a workflow cannot do it, and the instance release.
3. Keep the project's code, secrets, tokens, URLs of private hosts and file contents out of
   the issue.
4. Do not file the issue. The owner or the client's human files it under their own GitHub
   identity. No bot and no instance files issues.
